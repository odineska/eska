# Сворачиваемые группы в предпросмотре Linux

Конфигуратор 8.3.27.2342, «Такси», Linux ARM64, 96 DPI, масштаб 100%,
совместимость 8.3.27. Контрольные формы импортированы и повторно выгружены
в Designer XML. Основные 16 форм сняты в ru/en с одинаковой геометрией.
Дополнительные 11 форм сняты в en. Прямоугольники указаны от внешней рамки
включительно с кнопками выбора. Для замера использованы заливки областей
значений и границы контролов.

`ControlRepresentation=Picture` добавляет стрелку и отступ заголовка
20 px. Заголовок без подчёркивания занимает на 2 px меньше по высоте,
чем гиперссылка. При `ShowLeftMargin=false` поля начинаются на 10 px левее.
`StrongSeparation` сохраняет собственный отступ под линию. Скрытый
заголовок убирает управление и его отступ. При открытии Конфигуратор
показывает группу раскрытой, в том числе при `Collapsed=true`.
В Explorer сворачивание и раскрытие синхронизируются между окнами.

У вертикального ряда строковых и ссылочных полей ширина общей колонки
учитывает минимальное место для контролов. При наличии места для
двухстрочных подписей они сохраняются. Это правило действует и для
обычной группы с тем же набором полей.

| `Width` формы | Рамка, px | Колонка подписей, px | Поле «Внешняя система», px |

| 19 | 224×306 | 55 | [82, 62, 121, 23] |

| 31 | 344×261 | 74 | [101, 62, 222, 23] |
| 33 | 364×240 | 113 | [140, 62, 203, 23] |

В установленном VSIX совпали рамки и 92 прямоугольника полей в 25 из 27
контрольных форм. В двух оставшихся формах с `Width=13` и `Width=17`
Конфигуратор переносит подписи над полями, Explorer оставляет их сбоку.
Геометрия стрелки сверялась по занимаемому месту. Растр стрелки и
сравнение с Конфигуратором Windows требуют отдельного замера.

## Stalingrad

Для «Поступления на счёт текущих расчётов» использован исходный
`Documents/ПоступлениеНаСчетТекущихРасчетов/Forms/ФормаДокумента/Ext/Form.xml`.
Эталон — верхняя часть кадра 646×760 px при режиме экрана 1024×768.
В группе «Служебные» подписи помещаются на двух строках. Ширина всех пяти
полей стала 240 px вместо 259 px.

Прогоны до и после включали три размера «Выдачи займа», два размера
«Поступления на расчётный счёт» и пять размеров «Поступления на счёт

между сборками во всех измеренных состояниях. При ширинах 994–1430 px
в третьей форме переместились только поля «Служебных». Для полного
сравнения этой формы с Конфигуратором остаются отступы других групп и

## Проверки установленного расширения

Для изменения Explorer `cf2da01` в VS Code 1.109.0 прошли
`groups`, `through-align`, `responsive`,
`group-spacing` и `application` в ru/en. Всего 438 наблюдений.
`groups` проверяет смену представления, отступа и ширины по
несохранённому XML, сохранение узлов и выбора и обмен состоянием
группы между вкладкой и отдельным окном. На трёх формах Stalingrad
проверены 214 выборов в инспекторе и 12 изменений размеров на локаль.

У артефактов замеров и приёмки одинаковый SHA-256 манифеста ресурсов
`f85d1bd7e07e61af9fc990bd565602f46176ad4e7b5ab832fc66aec144229f61`.
Проверка типов и сборка прошли. Bun — 678 pass, 85 skip, 0 fail.
